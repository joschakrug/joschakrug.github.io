# joschakrug.github.io

Source for [joschakrug.github.io](https://joschakrug.github.io), built with [Jekyll](https://jekyllrb.com) and the [Minima](https://github.com/jekyll/minima) theme.

## Previewing changes locally

1. Install dependencies (first time only):
   ```
   bundle install
   ```

2. Start the local development server:
   ```
   bundle exec jekyll serve
   ```
   (If the default port 4000 is taken already, specify a different port using the option `--port XXXX`)

3. Open [http://localhost:4000](http://localhost:4000) in your browser.

The server watches for file changes and rebuilds automatically. Changes to `_config.yml` require a server restart.

## Deploying

Push to the `main` branch — GitHub Pages builds and deploys automatically.
